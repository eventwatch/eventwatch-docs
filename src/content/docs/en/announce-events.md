EventWatch is a service for finding events in Japan by area, category, and date. Organizers can announce their events by listing them on EventWatch.

## What happens when you list an event

- It appears in EventWatch's event lists and search. People can narrow results by place, date, category, and keyword
- The event page shows your organizer name as the host. The name is your organizer's display name, which you set when you list your first event
- When the event page is shared on social media and elsewhere, its title, description, and image appear as a preview

## Fees

For fees, see Article 6 (Fees and Payment) of the [Terms of Service](https://eventwatch.app/en/terms).

## From sending to publication

EventWatch checks (reviews) the details of each event before publishing it.

| Status | Meaning |
| --- | --- |
| **Under review** | EventWatch is checking the details. It is published when the check is done |
| **Published** | It appears in EventWatch's lists and search |
| **Changes requested** | There is something to fix (sent back). Read the reason, fix it from **Fix and resubmit**, and send it again |

People do the check, so publication can take some time. We don't give an estimate of how many days the check takes.

## Events you can list

You can list events like these. See the [posting guidelines](https://eventwatch.app/en/post/guidelines) for details.

- The date, time, and location are decided. Online events are fine
- The organizer is announcing it, or you announce it at the organizer's request
- Anyone can consider joining. Events that need an application or a lottery are fine

You can't list the following:

- The date, time, or location isn't decided yet
- Participation is limited, and there's no need to announce it publicly
- It only promotes a product or service, with no real event
- It reposts text or images made by others without permission

## Choose how to list

| Method | Best for | Start |
| --- | --- | --- |
| Post on the web | Listing events one at a time. First-time organizers | [Post an event](https://eventwatch.app/en/post) |
| Create drafts with an AI assistant | Organizers who have a flyer or an announcement and want AI to fill in the details | [Create drafts with an AI assistant](/en/ai-assistants/connect) |
| Send with the WordPress plugin | Organizers who run their own site on WordPress | [Get started with the WordPress plugin](/en/wordpress/setup) |

### Post on the web

1. Open [Post an event](https://eventwatch.app/en/post).
2. Enter the event details. Four things are required: name, start time, category, and location (not needed for online events). You can add the other details later.
3. Select **Send this event**. You log in with your Google account when you send it.
4. If this is your first event, enter your organizer name. It's shown with your events, and you can change it later.

Events you send are **Under review**.

Instead of entering the details yourself, you can also send us the event page's URL and ask us to list it ([Request a listing by URL](https://eventwatch.app/en/post/request)).

### Create drafts with an AI assistant

When you connect an AI assistant such as Claude or ChatGPT to EventWatch, it can create drafts from a flyer image or an announcement. AI assistants create drafts only; you send them for review yourself. Before connecting, list one event on the web to create your organizer.

How to connect is in [Create drafts with an AI assistant](/en/ai-assistants/connect). Once connected, you can ask like this:

- With a flyer image: "Post this flyer to EventWatch as a draft."
- To fix a draft it made: "Change the start time of that draft to 6 p.m."

### Send with the WordPress plugin

Events you publish on your WordPress site can be sent to EventWatch as they are. There's no separate send button; publishing on your site sends the event. It appears on your site without waiting for EventWatch's check.

The plugin is being prepared for release in the WordPress plugin directory. The steps are in [Get started with the WordPress plugin](/en/wordpress/setup).

## After listing

On EventWatch's **Your events**, you can edit, take down, and delete your events.

- You can edit published events. To stop listing one, select **Take down**
- Editing an event while it's under review returns it to a draft, and the check doesn't start until you send it for review again
- Published events can't be deleted. Take them down first, then delete them. Deleting can't be undone
