title: MCP のツール
description: EventWatch の MCP サーバーが持つ 8 つのツールの入力・上限・返す値と、共通の制約・エラーです。
---

EventWatch の MCP サーバーは、次の 8 つのツールを持ちます。接続と認証は [MCP の接続と認証](/mcp/authentication) にあります。

| ツール | 種類 | 内容 |
| --- | --- | --- |
| `get_organization` | 読み取り | つないだ主催者の識別子と名前 |
| `list_event_options` | 読み取り | カテゴリーと都道府県の ID |
| `search_tags` | 読み取り | タグの候補 |
| `list_event_drafts` | 読み取り | AI アシスタントが作った下書きの一覧 |
| `get_event_draft` | 読み取り | AI アシスタントが作った下書き 1 件と、差し戻しの理由 |
| `create_event_draft` | 書き込み | 下書きを作る |
| `update_event_draft` | 書き込み | 下書きを直す |
| `attach_event_image` | 書き込み | 会話に添付された画像を下書きに付ける |

## 共通の制約

- **確認に出す・公開する・非公開にする・削除するツールはありません。** 確認に出すのは主催者が EventWatch の画面で行います
- 扱えるのは、AI アシスタントが作った下書きのうち、未提出（`draft`）と差し戻し（`rejected`）のものだけです。人が Web で作った下書き・ほかの主催者の下書き・無い下書きは「見つからない」になります
- 確認に出した後・公開中・非公開の下書きは変えられません。WordPress のサイトと結び付いた下書きは、サイトの側で編集します
- AI アシスタントが作った未提出の下書きは、主催者ごとに 50 件までです
- 書き込みの流量は、許可 1 件ごとに 1 分あたり 60 回です（[流量と上限](/api/rate-limits)）
- 日時は `YYYY-MM-DD HH:mm` の形で、`zoneId`（既定は `Asia/Tokyo`）の時刻として読みます

## 返す値

下書きを返すツールは、下書きの項目に `editUrl`（主催者の編集画面の URL）を足して返します。作成・更新・画像のツールは、主催者に伝える注記を `notes` に並べます。

- 下書きで未公開であること。`editUrl` で確かめて確認に出すよう主催者に伝えること
- 画像が無いときは、編集画面で足せること

作った後は、`editUrl` を主催者に渡してください。

## 各ツール

### `get_organization`

入力はありません。つないだ主催者の `id` と `displayName` を返します。

### `list_event_options`

入力はありません。カテゴリーと都道府県（1〜47）の `id`・`nameJa`・`nameEn` を返します。下書きの `category` と `prefectureCode` には、ここの ID を使います。

### `search_tags`

| 入力 | 型 | 内容 |
| --- | --- | --- |
| `query` | 文字列（必須） | タグの名前の前方一致。前後の空白を除いて 1〜100 字 |

タグは ID でしか付けられません。新しいタグは作れません。

### `list_event_drafts`

| 入力 | 型 | 内容 |
| --- | --- | --- |
| `page` | 整数 | 0 から始まるページ番号。既定は 0 |
| `size` | 整数 | 1 ページの件数。1〜100、既定は 20 |

`total` と `list` を返します。新しい順です。作る前に、同じ下書きが無いかをここで確かめてください。

### `get_event_draft`

| 入力 | 型 | 内容 |
| --- | --- | --- |
| `id` | UUID（必須） | 下書きの ID |

差し戻されたときは、その理由も返します。

### `create_event_draft`

必須は `title` だけです。

| 入力 | 型 | 内容 |
| --- | --- | --- |
| `title` | 文字列（必須） | 1〜256 字 |
| `startAt` | 日時 | 開始。`occurrenceRanges` を送らないときは必須 |
| `closeAt` | 日時 | 終了。省くと開始と同じ |
| `occurrenceRanges` | 配列 | 日程が複数あるとき。`startAt`・`closeAt` の組を 1〜100 組。重なる・接する組は送れません。`startAt`・`closeAt` と一緒に送りません |
| `holdingPeriodNote` | 文字列 | 日程の補足（例: 毎週土曜 10:00〜12:00）。200 字まで |
| `zoneId` | 文字列 | 時間帯の ID。64 字まで。既定は `Asia/Tokyo` |
| `description` | 文字列 | 本文（Markdown）。10,000 字まで。画像の記法は断られます |
| `category` | 整数 | カテゴリーの ID |
| `prefectureCode` | 整数 | 都道府県の ID（0〜47）。オンライン開催でなければ必須 |
| `online` | 真偽値 | オンライン開催か |
| `venueName`・`venueAddress` | 文字列 | 会場名（256 字まで）と住所（512 字まで）。組で送ります |
| `venueId` | 文字列 | 会場の ID。36 字まで |
| `placeId`・`latitude`・`longitude` | 文字列・数値 | Google の Place ID（256 字まで、英数字・`_`・`-`）と緯度・経度。組で送ります |
| `tagIds` | 文字列の配列 | `search_tags` のタグの ID。10 件まで |
| `publisherEventPageUrl` | 文字列 | 主催者自身のイベントのページの URL（http または https）。1024 字まで。主催者の中で重なると断られます |

**同じ値の作成を 72 時間以内に送り直すと、新しく作らずに前に作った下書きを返します。** 返した下書きが確認に出された後でも返すので、`status` を見てください。

### `update_event_draft`

`id`（UUID）が必須で、ほかの項目は `create_event_draft` と同じです。加えて `imageUploadId` を受けます（`""` で画像を外します）。

- **送った項目だけが変わります。** `null` と省略は今の値のままです
- 文字の項目は `""` で消します。`tagIds` は送ると全部を置き換え、`[]` で消します。`title` は消せません
- 開始と終了が違うイベントの日付を移すときは、`startAt` と `closeAt` の両方を送ります
- 日程が 2 組以上ある下書きに `startAt`・`closeAt` を送ると断られます。`occurrenceRanges` を送って全部を置き換えてください
- 差し戻された下書きを直しても、差し戻しの状態と理由は残ります。主催者が確認に出すと消えます

### `attach_event_image`

| 入力 | 型 | 内容 |
| --- | --- | --- |
| `id` | UUID（必須） | 下書きの ID |
| `file.download_url` | 文字列（必須） | 会話に添付されたファイルの一時 URL。4096 字まで |
| `file.file_id` | 文字列（必須） | ファイルの ID。512 字まで |
| `file.mime_type` | 文字列 | MIME タイプ |
| `file.file_name` | 文字列 | ファイル名 |

- 受けるのは、AI アシスタントの会話に添付されたファイルの一時 URL だけです。いまは ChatGPT の添付だけを受けます。Web 上の任意の画像の URL と base64 は受けません
- 形式は JPEG・PNG・WebP、大きさは 10 MiB までです。転送（リダイレクト）は追いません
- 受けられないときはエラーの結果を返し、主催者に編集画面で画像を付けるよう案内します

画像の投入の上限は [流量と上限](/api/rate-limits) にあります。

## エラー

ツールの中のエラーは、`isError: true` のツールの結果として、主催者に伝えられる英語の文で返ります。

| 状況 | 結果の内容 |
| --- | --- |
| 値が規則に合わない | 断った値と理由。直して送り直せます |
| 下書きが見つからない | AI アシスタントが作った下書きだけが対象であること |
| 確認に出した後・公開中 | ここからは変えられないこと |
| WordPress のサイトと結び付いている | サイトの側で編集すること |
| 下書きが 50 件に達した | EventWatch で確認に出すか削除すること |
| ページの URL が重なるなどの衝突 | 衝突したこと |
| 流量を超えた | 1 分待って送り直すこと |
| 許可が使えなくなった | 主催者につなぎ直してもらうこと |
| 主催者が停止されている | EventWatch に問い合わせること |
| そのほか | 一時的に使えないこと |
