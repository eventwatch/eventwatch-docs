---
title: 流量と上限
description: EventWatch の API の流量の制限と、ページ送り・画像・下書きの上限です。
---

## 流量

| 対象 | 上限 | 超えたとき |
| --- | --- | --- |
| 書き込み（`GET` 以外） | キーごとに 1 分あたり 60 回 | 429。`code` は `orgApiKeyRateLimitExceeded`、`Retry-After` は次の窓までの秒数 |
| すべての要求 | IP ごとの上限があります | 429。`code` も `Retry-After` もありません |

書き込みの窓は 1 分ごとに区切られ、窓が変わると数え直します。超えたときの扱いは [送り直しの扱い](/api/retries) を見てください。

## ページ送り

一覧の操作は `page` と `size` を受け取ります。

| パラメーター | 内容 |
| --- | --- |
| `page` | 0 から始まるページ番号 |
| `size` | 1 ページの件数。既定は 20、上限は 100 です。100 を超えると 400 になります |

[取り込める投稿の一覧](/api/operations/listlinkableevents/) は、結び付けると投稿が一覧から消えて位置がずれます。続けて取り込むときは `page=0` を読み直してください。

## 識別子

| 項目 | 形 |
| --- | --- |
| `siteId` | 英数字とハイフンで 64 字まで |
| `postId` | 数字で 20 字まで |

## 画像

[画像の投入](/api/operations/uploadimage/) は `multipart/form-data` で、`file` と `purpose` を送ります。

| 項目 | 上限 |
| --- | --- |
| 形式 | JPEG・PNG・WebP。ファイルの中身で判定します |
| 大きさ | 要求の本文全体で 10 MiB まで。超えると 413 になります。ちょうど 10 MiB のファイルは、フォームの境界の分で超えます |
| `purpose` | `ownedEventImage`（アイキャッチ）か `ownedEventDescriptionImage`（本文の画像） |
| 投入の量 | 団体ごとに 24 時間で 100 件。超えると 409 になります |

## 下書き

AI アシスタントが作った未提出の下書きは、団体ごとに 50 件までです。51 件目は 409（`code` は `aiDraftLimitExceeded`）になります。すでに作った下書きの再送は、上限に達していても成功します。
