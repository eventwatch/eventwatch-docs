---
title: 互換性の約束
description: EventWatch の API を変えるときの約束と、破壊的変更の予告の期間です。
---

配布済みの WordPress プラグインの古い版は、利用者のサイトに残り続けます。API を安心して使い続けられるよう、次のことを約束します。

## 破壊的変更

次の変更を破壊的変更として扱います。

- 操作や項目を削除する
- 項目の型を変える
- 任意の項目を必須にする

## 破壊的変更をするとき

今の URL の意味を変えません。新しい版を `/api/v2.0/` のように足して、今の版と並べて動かします。

**今の版は、新しい版の公開から最低 6 か月動かしてから止めます。** 予告はこのサイトに載せます。

## 破壊的変更にしないもの

次の変更は予告なく行います。受け取る側は、知らない項目を無視してください。

- 操作を足す
- 応答に項目を足す
- 任意の項目を要求に足す

## 版

URL の版（`/api/v1.0/`）と、[API の概要](/api/) に出る版（`1.0`）は揃っています。破壊的でない変更では版を上げません。

## エラーの扱い

[API の操作のページ](/api/) に載せている応答は成功だけです。エラーの形と `code` は [エラーの形と code](/api/errors) に書いています。`code` の削除や意味の変更も、破壊的変更と同じ約束で扱います。新しい `code` は予告なく足すことがあるので、知らない `code` はステータスで扱ってください。

## 変更を知るには

[変更履歴の見方](/changelog) を見てください。
