---
title: 掲載の状態
description: WordPress プラグインに表示される掲載の状態の一覧です。掲載の確認中（審査）、修正のお願いがあります（差し戻し）などの意味と、次にすることをまとめています。
---

状態は、編集画面の「EventWatch」パネルと、イベント一覧の「EventWatch」列に出ます。列は API キーを入れているときだけ出ます。

| 状態 | 意味 | 次にすること |
| --- | --- | --- |
| 未送信 | まだ EventWatch に送っていない | 投稿を公開する。公開中なら次の更新で送る |
| 送信待ち | まもなく送る。ふつうは数分で終わる | 待つ |
| 掲載の確認中 | EventWatch が内容を確かめている（審査中） | 待つ |
| 掲載中 | EventWatch に掲載されている | 更新すると EventWatch にも反映する |
| 修正のお願いがあります | EventWatch から修正を頼まれている（差し戻し）。理由がパネルに出る | 直して投稿を更新する。もう一度送る |
| 掲載を止めています | EventWatch が掲載を止めている。サイトでの公開は続く | パネルの「EventWatch に問い合わせる」から問い合わせる |
| 公開を取り下げています | サイトで公開していないので、EventWatch でも公開していない | 公開すると、もう一度掲載する |
| 送信に失敗 | EventWatch に送れなかった | パネルの理由を見る（[送れないときの対処](/wordpress/troubleshooting)） |
| EventWatch に送らない | 「この投稿を EventWatch に送る」がオフ | 送るときはオンにして、投稿を更新する |

## Web の表示との違い

EventWatch の「投稿の管理」では、同じ状態を次の語で表示します。

| プラグイン | EventWatch の Web |
| --- | --- |
| 掲載の確認中 | 掲載の確認中 |
| 掲載中 | 公開中 |
| 修正のお願いがあります | 修正のお願い |
| 掲載を止めています | 掲載停止中 |

## 状態の更新

プラグインは、編集画面を開いたときと、約 1 時間ごとに最大 30 件、EventWatch の状態を読みます。イベントが多いサイトでは、全件が一巡するまで時間がかかります。最新の状態を見るときは、編集画面を開いてください。

確認にかかる時間の目安はお伝えしていません。確認は自動ではないため、公開まで時間がかかることがあります。

## パネルのそのほかの表示

| 表示 | 内容 |
| --- | --- |
| 理由 | 送れなかった理由 |
| EventWatch からの理由 | 修正のお願いの理由 |
| 次に送り直す時刻 | 自動で送り直す予定の時刻 |
| 最後に送った日時 | 最後に送った日時 |
| EventWatch で見る | 掲載中のページを開く |
