---
title: イベントのページを組み替える
description: WordPress プラグインが作るイベントのページの URL と、サイトエディターでの並べ替えの方法です。
---

公開したイベントには、それぞれのページができます。URL は `/event/イベントのスラッグ/` です。

## URL を変える

`event` の部分は、「設定 › EventWatch」の「イベントのページ」にある「URL の接頭辞」で変えられます。古い URL は新しい URL へ転送されます。WordPress のパーマリンクの設定が「基本」のあいだは、URL はこの形にならず、接頭辞も効きません。

同じ節の「イベント一覧のページ」は、イベントのページの「イベント一覧へ戻る」の行き先です。選ぶまでリンクは出ません。

## 既定の並び

ページは次の順で表示します。

1. イベント一覧へ戻るリンク（「イベント一覧のページ」を選んだとき）
2. カテゴリ
3. タイトル
4. アイキャッチ画像
5. 本文
6. 日時
7. 会場
8. 主催（サイトの名前）
9. 地図（会場の情報があるとき）
10. カレンダーに追加・気になる・共有のボタン（「気になる」は EventWatch に掲載中で、これからの日程があるとき）
11. 公式ページへのリンク（「別の公式ページ」を入れたとき）

パスワードで保護したイベントは、パスワードが入力されるまで、タイトルと入力欄だけを表示します。

ページには schema.org の `Event` のデータ・説明・Open Graph のタグも出力します。SEO プラグインとの分担は[フィルター](/wordpress/filters)で変えられます。

## サイトエディターで組み替える

ブロックテーマでは、サイトエディターで並びを変えられます。

1. 「外観」の「エディター」を開き、テンプレートの「イベントの詳細」を開きます。
2. 次のブロックを動かす、消す、足すなどして並びを変えます。
3. 保存します。

| ブロック | 出すもの |
| --- | --- |
| イベントの詳細の欄 | 日時や会場など、イベントの詳細の 1 つの欄 |
| イベントの操作 | カレンダーに追加・気になる・共有のボタンの列 |

「イベントの詳細の欄」は、挿入の一覧に欄ごとの名前で出ます。

| 名前 | 出すもの |
| --- | --- |
| イベント一覧へ戻る | 一覧へ戻るリンク |
| イベントのカテゴリ | カテゴリ |
| イベントの日時 | 日時 |
| イベントの会場 | 会場 |
| イベントの主催 | 主催 |
| イベントの地図 | 地図（[地図の表示](/wordpress/maps)） |
| カレンダーに追加 | カレンダーに追加のボタン |
| 気になる | 気になるのボタン |
| 共有 | 共有のボタン |
| 公式ページを見る | 公式ページへのリンク |

テーマに `single-eventwatch_event.html` というテンプレートがあれば、そちらが優先されます。

## クラシックテーマのとき

プラグインの `templates/single-event.php` を、テーマの `eventwatch` フォルダにコピーして編集します。テーマに `single-eventwatch_event.php` を足しても変えられます。
