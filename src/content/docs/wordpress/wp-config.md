description: EventWatch の API キーを、データベースではなく wp-config.php に置く方法です。
---

:::caution[準備中です]
EventWatch の主催者のログインと API キーの発行は、まだ開いていません。このページの手順は、公開の後に使えるようになります。
:::

設定画面に保存したキーは、データベースのバックアップやサイトの複製にも含まれます。`wp-config.php` に置くと、データベースにキーを持たずに済みます。

## 手順

すでに設定画面にキーを保存しているときは、先に「キーを削除」を押します。定数を足しても、保存したキーはデータベースに残ります。定数があるあいだは「キーを削除」のボタンが出ません。

`wp-config.php` の `require_once ABSPATH . 'wp-settings.php';` の行より上に書きます。

```php
define( 'EVENTWATCH_API_KEY', 'ewk_...' );
```

WordPress の「設定」の「EventWatch」を開き、「接続を確かめる」を押します。

## 設定したときの動き

- 保存したキーより、定数が優先されます
- 設定画面の欄は読み取りだけになり、キーの変更と削除のボタンは出ません
- 定数を別のキーに変えると、接続は確かめ直しになります
- 定数を消すと、データベースに残っている保存したキーがまた使われます

## キーを入れ替える

このサイトから古いキーで送ったことがあるときは、先に EventWatch の「サイトとの連携」で古いキーを失効させてから、定数を新しいキーに変えます。古いキーが有効なあいだは、「接続を確かめる」が成功しても、送信は断られます。

## マルチサイト

定数はネットワークのすべてのサイトに効きます。サイトごとに別のキーを使うときは、定数を使わず、各サイトの設定画面に保存してください。

## サイトを複製するとき

定数のキーは、設定画面の「複製」の確認では消せません。複製先から送らないようにするには、複製先の `wp-config.php` から定数を消してください。[サイトの URL が変わったとき](/wordpress/site-url) も見てください。
