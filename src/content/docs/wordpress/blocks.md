---
title: ブロックでイベントを表示する
description: WordPress のページにイベント一覧・イベントの検索・終了したイベントのブロックとパターンを置く方法です。
---

プラグインのブロックは、ブロックエディターの挿入の一覧から追加します。色と書体はテーマに合わせて表示され、ブロックの設定で変えられます。

## ブロック

| ブロック | 出すもの |
| --- | --- |
| イベント一覧 | サイトの開催予定のイベント |
| イベントの検索 | 開催予定のイベントを、キーワード・期間・カテゴリ・都道府県で探す欄と結果 |
| 終了したイベント | サイトの終わったイベントを、新しい順に |

### イベント一覧

カードかリストか、1 ページの件数、並び順を選べます。カテゴリ・タグ・都道府県・期間で絞れます。

公開中でまだ終わっていないイベントだけが並びます。日程の無いイベントと、パスワードで保護したイベントは並びません。

並びの基準は、カードに出る日付です。まだ終わっていない次の日程で、期間で絞っているときはその期間の中の最初の日程です。期間で絞ると、日程のどれかがその期間に重なるイベントだけが並びます。

次の 2 つは、イベント一覧のブロックをあらかじめ設定した形で、挿入の一覧に別の名前で出ます。

| 名前 | 出すもの |
| --- | --- |
| 今月のイベント | 今月のイベントのうち、まだ終わっていないもの |
| 近日のイベント | 30 日以内のイベント |

### イベントの検索

キーワードは、イベントのタイトル・本文・会場名に当たります。検索の条件はページの URL に入るので、そのまま共有でき、ブラウザーの戻るボタンも使えます。結果はページを読み直さずに入れ替わります。JavaScript が無くても検索できます。

### 終了したイベント

イベントは、終わった翌日からここに移ります。カードかリストか、1 ページの件数、どこまでさかのぼるかを選べます。既定は 1 年です。

## パターン

挿入の一覧の「パターン」にある「EventWatch」の分類から、組み合わせ済みの節を置けます。見出しは編集できます。

| パターン | 中身 |
| --- | --- |
| 今月のイベント | 今月のイベントの一覧 |
| 近日のイベント | 30 日以内のイベントを 3 件 |
| 終了したイベント | 終了したイベントの一覧 |
| 開催予定と終了したイベント | 開催予定のリストと終了したイベント |

## クラシックテーマのとき

ブロックが使えないテーマでは、ショートコードを本文に書きます。

```text
[eventwatch_events layout="list" per_page="6"]
[eventwatch_past_events layout="list" per_page="6" months="12"]
[eventwatch_search layout="list" per_page="6"]
```
