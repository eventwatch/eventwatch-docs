---
title: EventWatch の投稿を取り込む
description: EventWatch の Web で作った団体の投稿を、WordPress のイベントとして取り込む手順です。
---

EventWatch の Web で作った団体の投稿を、WordPress のイベントにできます。内容と画像を取り込み、画像はメディアライブラリにコピーします。

:::caution
取り込んだ投稿は、以後サイトで編集します。EventWatch では編集できなくなります。
:::

## 手順

API キーを入れたサイトの管理者だけが使えます。

1. 「イベント」の「EventWatch から取り込む」を開きます。
2. 取り込む投稿を選びます。1 回に選べるのは、表示中のページ（20 件）の中からです。
3. 「選んだ投稿を取り込む」を押します。
4. 終わるまで、このページを開いたままにします。

1 件ずつ処理し、ページを閉じると止まります。取り込みが終わらなかったときは、下書きがサイトに残ります。「やり直す」を押しても、同じ投稿を 2 件作ることはありません。

## 取り込んだ後の状態

| EventWatch での状態 | サイトでの状態 |
| --- | --- |
| 掲載中 | 公開 |
| それ以外 | 下書き |

取り込みでは、イベントの内容を EventWatch へ送り返しません。下書きを保存しても、確認の途中の投稿が確認から外れることはありません。

下書きや「修正のお願い」の投稿は、サイトで公開すると確認に出ます。

取り込みが終わったら、内容を確かめてください。

## 取り込めないとき

「取り込める投稿はありません。」と出るときは、その API キーの団体が EventWatch で作った投稿が無いか、すべて取り込み済みです。キーの団体は「設定 › EventWatch」の「接続を確かめる」で確かめられます。

「サイトの URL が変わっています。」と出たときは、先に[サイトの URL が変わったとき](/wordpress/site-url)の確認をしてください。
