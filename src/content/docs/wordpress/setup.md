WordPress のサイトで公開したイベントを、そのまま EventWatch に載せられます。このページでは、プラグインを入れて最初のイベントを送るまでを順に進めます。

:::caution[準備中です]
プラグインは WordPress の公式ディレクトリへの公開を準備しています。EventWatch の主催者のログインと API キーの発行も、まだ開いていません。このページの手順は、公開の後に使えるようになります。
:::

画面の名前は、プラグイン 0.1.0 の日本語の表示に合わせています。

## 用意するもの

- WordPress 6.7 以上、PHP 7.4 以上のサイトと、その管理者の権限
- EventWatch のアカウント（Google アカウントでログインします）
- EventWatch の団体。団体は、最初のイベントを載せるときに作られます。団体がまだ無いと「サイトとの連携」のリンクが出ないので、先に EventWatch の「イベントを載せる」から 1 件載せてください

自分のサイトでイベントを管理するだけなら、EventWatch のアカウントと API キーは要りません。キーを入れないあいだ、イベントはサイトの中だけに置かれ、何も送りません。

## 1. プラグインを入れる

1. WordPress の管理画面で「プラグイン」から新しいプラグインを追加します。
2. 「EventWatch Events」を探して、インストールして有効化します。

管理画面のメニューに「イベント」が増えます。

## 2. API キーを発行する

API キーは、サイトと EventWatch の団体をつなぐ文字列です。団体の管理者だけが発行できます。サイトごとに 1 つ発行してください。

1. EventWatch にログインし、「投稿の管理」を開きます。
2. 見出しの横のリンク「サイトとの連携」を開きます。プラグインの画面の案内では、この場所を「団体の設定 › サイトとの連携」と書いています。
3. 「キーを発行する」を押します。
4. どのサイトで使うかが分かる名前を入れて「発行する」を押します。
5. 表示されたキーを「コピー」します。

:::caution
画面を閉じると、このキーは二度と表示できません。次の手順で WordPress に貼ってから閉じてください。キーをなくしたときは、そのキーを失効して、新しく発行してください。
:::

## 3. キーを WordPress に入れる

1. WordPress の管理画面で「設定 › EventWatch」を開きます。
2. 「EventWatch との接続」の「EventWatch の API キー」にキーを貼ります。
3. 変更を保存します。
4. 「接続を確かめる」を押します。

「EventWatch とつながっています」の後ろに団体の名前が出れば、準備は終わりです。名前が別の団体のときは、キーを取り違えています。

キーを保存すると、EventWatch の[利用規約](https://eventwatch.app/terms)と投稿ガイドラインに同意したものとみなします。

ここに保存したキーは、データベースのバックアップやサイトの複製にも含まれます。`wp-config.php` を編集できるなら、次の形で設定することをおすすめします。こちらが優先され、設定画面では変更できなくなります。

```php
define( 'EVENTWATCH_API_KEY', 'ewk_...' );
```

## 4. イベントを公開して送る

1. 「イベント」の「イベントを追加」を開きます。
2. タイトルを入れ、右のサイドバーの「イベントの情報」に日程を入れます。EventWatch に送るには、「EventWatch のカテゴリ」と「都道府県」も選びます（オンライン開催なら都道府県は要りません）。
3. 同じサイドバーの「EventWatch」パネルで、「この投稿を EventWatch に送る」がオンであることを確かめます。既定でオンです。
4. イベントを公開します。

送る専用のボタンはありません。公開すると自動で送ります。サイトには公開と同時に出ます。

## 5. 掲載の状態を見る

「EventWatch」パネルの状態が「送信待ち」から「掲載の確認中」に変わります。EventWatch が内容を確かめて、掲載されると「掲載中」になります。

直してほしい点があるときは「修正のお願いがあります」と理由が出ます。直して投稿を更新すると、もう一度送ります。状態の意味は[掲載の状態](/wordpress/listing-status)にまとめています。

送れないときは、パネルに理由が出ます。[送れないときの対処](/wordpress/troubleshooting)を見てください。
