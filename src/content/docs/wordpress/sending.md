---
title: イベントを送る・取り下げる
description: WordPress プラグインで、イベントの更新・取り下げ・削除が EventWatch にどう伝わるかと、公開中のイベントをまとめて送る方法です。
---

API キーを入れたサイトでは、イベントを公開すると自動で EventWatch に送ります。予約投稿は、公開の時刻に送ります。

EventWatch の確認は、EventWatch での掲載にだけ影響します。サイトには公開と同時に出ます。

## 操作ごとの動き

| サイトでの操作 | EventWatch での結果 |
| --- | --- |
| 公開する | 送る。確認の後に掲載される |
| 公開中のイベントを更新する | 更新を送る。掲載中はそのまま掲載が続く |
| 下書き・レビュー待ち・非公開・パスワード保護にする、ゴミ箱に入れる | 送ってあれば取り下げる |
| ゴミ箱から戻す | もう一度公開するまで送らない |
| 完全に削除する | 送ってあれば EventWatch でも削除する |
| 「この投稿を EventWatch に送る」をオフにする | サイトだけに置く。送ってあれば取り下げる |

内容が変わっていない更新は送りません。「修正のお願いがあります」のあいだは、同じ内容でも送り直します。送るときに投稿を読み直すので、送るのはその時点の最新の内容だけです。

## 送る内容

- タイトル・本文・日時・日程の補足・カテゴリ・都道府県・オンライン開催の設定・会場名と住所・公式ページの URL
- アイキャッチ画像 1 枚

本文の見出し・段落・リスト・引用・リンク・強調・打ち消し線・コード・表は送ります。本文に入れた画像と埋め込みは送りません。EventWatch から取り込んだイベントの本文の画像は、EventWatch の本文に残ります。

アイキャッチ画像は、保存の少し後に送ります（ふつうは 1 分ほど）。上げ直すのはファイルが変わったときだけです。アイキャッチ画像を外すと、EventWatch の画像も外れます。

## 公開中のイベントをまとめて送る

キーを入れる前に公開したイベントは、自動では送りません。次に更新したときに送るか、次の操作でまとめて送ります。

1. 「設定 › EventWatch」を開きます。
2. 「EventWatch への送信」の「公開中でまだ送っていないイベント」の件数を確かめます。
3. 「EventWatch へまとめて送る」を押します。

どのイベントも EventWatch の審査（「掲載の確認中」）に並びます。WP-Cron で数十件ずつ送るので、時間がかかることがあります。

「送らない」にしたイベント、終了したイベント、必要な項目が足りないイベントは含みません。

EventWatch には 1 日に上げられる画像の上限があります。画像付きのイベントが 100 件を超えるサイトでは、内容が先に届き、画像の一部は翌日以降に届きます。
