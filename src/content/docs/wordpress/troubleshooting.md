---
title: 送れないときの対処
description: WordPress プラグインから EventWatch にイベントを送れないときの、必須の項目・画像の上限・WP-Cron の遅れ・API キーの問題の直し方です。
---

送れないときは、編集画面の「EventWatch」パネルに理由が出ます。サイトでの公開には影響しません。パネルが見えないときは、エディターの通知から確かめられます。

## 項目が足りない・長すぎる

パネルに「EventWatch に送れません」と出たら、次の点を直して投稿を更新します。

| 項目 | 条件 |
| --- | --- |
| タイトル | 必須。256 字まで |
| 日程 | 1 つ以上必須 |
| EventWatch のカテゴリ | 必須。サイトのカテゴリーとは別に選ぶ |
| 都道府県 | オンライン開催でなければ必須 |
| 会場名と住所 | 両方入れるか、両方空にする。会場名は 256 字、住所は 512 字まで |
| 日程の補足 | 200 字まで |
| 公式ページの URL | 1024 字まで |
| 本文 | 送る形に変換した後で 10,000 字まで |

会場名・住所・日程の補足・公式ページの URL は、絵文字を 2 字と数えます。

## 画像を送れない

送るのはアイキャッチ画像 1 枚です。JPEG・PNG・WebP で 10 MB までです。大きすぎるときは、WordPress が作った縮小版を送ります。

| パネルの見出しと文 | 対処 |
| --- | --- |
| 形式が受け付けられない | JPEG・PNG・WebP の画像を選ぶ |
| 「上限の 10 MB を超えています」 | 小さい画像を選ぶ |
| 「このサイトで読み込めませんでした」 | 画像を選び直すか、別の画像を選ぶ |
| 「画像を EventWatch へ上げられませんでした」 | 1 時間に 1 回ほど、自動で送り直す |
| 「今日の画像の上限に達しました」 | 1 時間に 1 回ほど、自動で送り直す |

画像を送れなくても、ほかの内容は送ります。EventWatch にこのイベントの画像があれば、そのまま残ります。サイトの外に置いたファイルは送れません。

## 送信が遅い・止まっている

EventWatch とつながらないときは、自動で送り直します。間隔は 1 分、5 分、30 分、2 時間で、その後は 6 時間ごとです。「今すぐ送り直す」を押すと、待たずに送れます。

送り直しには WP-Cron を使います。**WP-Cron はサイトへのアクセスがあるときだけ動く**ので、アクセスの少ないサイトでは遅れます。時間どおりに送り直すには、[サーバーの cron から WP-Cron を動かします](https://developer.wordpress.org/plugins/cron/hooking-wp-cron-into-the-system-task-scheduler/)。

「設定 › EventWatch」の「EventWatch への送信」で、「最後に送信に成功した日時」と「送信待ち」の件数を確かめられます。「DISABLE_WP_CRON が有効なので」と出ているサイトでは、サーバーの cron から動かしていないと送り直しません。

## API キーの問題

「設定 › EventWatch」で「接続を確かめる」を押すと、次のように出ます。

| 表示 | 対処 |
| --- | --- |
| 「EventWatch とつながっています」 | 問題ありません |
| 「EventWatch の API キーの形ではありません」 | キーは `ewk_` で始まる 47 字です。全体をコピーし直す |
| 「EventWatch がこの API キーを受け付けませんでした」 | キーが失効したか、発行した人が団体を抜けた・管理者でなくなった可能性があります。団体の管理者に「サイトとの連携」で発行し直してもらう |
| 「EventWatch で団体が停止されているため」 | キーの問題ではありません。EventWatch に問い合わせる |
| 「失効していない別の API キーで EventWatch とつながっている」 | 「サイトとの連携」で古いキーを失効してから「接続を確かめる」を押す |
| 「EventWatch との接続を確かめられませんでした」 | 少し待ってから、やり直す |

キーの拒否や団体の停止で止まった送信は、新しいキーを入れるか、「接続を確かめる」が成功するか、イベントを更新するまで再開しません。

## そのほかの理由

| パネルの文 | 対処 |
| --- | --- |
| 「EventWatch の API キーがありません」 | 「設定 › EventWatch」でキーを入れる |
| 「サイトの URL が変わったので、送信を止めています」 | [複製か移転かを選ぶ](/wordpress/site-url) |
| 「同じ公式ページの掲載が EventWatch に既にあります」 | 同じイベントなら EventWatch に問い合わせる。別のイベントなら別の公式ページを入れて更新する |
| 「このイベントは EventWatch で削除されているので」 | もう一度は送れません。誤りだと思うときは EventWatch に問い合わせる |
| 「EventWatch がこのイベントの内容を受け付けませんでした」 | イベントの情報を確かめて、投稿を更新する |

問い合わせは [EventWatch のお問い合わせ](https://eventwatch.app/contact)からできます。
