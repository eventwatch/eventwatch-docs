---
title: プラグインを削除する
description: EventWatch Events プラグインを削除したときに、サイトと EventWatch に残るものと消えるものです。
---

プラグインを削除する前に、残るものと消えるものを確かめてください。

## サイト

| 対象 | 削除の後 |
| --- | --- |
| API キー・サイトの ID などの設定 | 消える |
| 各イベントの送信の記録 | 消える |
| プラグインが足した権限と予定の処理 | 消える |
| イベントの投稿 | **既定で残る** |
| 「送らない」の選択 | 残る |

イベントも消すときは、削除の前に「設定 › EventWatch」の「プラグインを削除するときに、イベントもすべて削除する」をオンにします。オンにして削除すると、このサイトのイベントを完全に削除し、元に戻せません。

## EventWatch

プラグインを削除すると、EventWatch にサイトの切り離しを伝えます。

- 送ってあった投稿は、**掲載されたまま**残ります
- 以後は EventWatch のダッシュボードから編集できます

EventWatch とつながらないときも、プラグインの削除は続きます。そのときは、EventWatch の「サイトとの連携」で API キーを失効してください。

URL が変わったことをまだ確認していないサイトの複製からは、切り離しを伝えません。

## 入れ直すとき

プラグインを入れ直すと、サイトは新しい ID になり、EventWatch では別のサイトとして扱います。残っていたイベントを公開すると、別の投稿として送られることがあります。
