---
title: 地図を表示する
description: WordPress プラグインのイベントのページに、会場の地図のリンクや Google マップの埋め込みを出す設定です。
---

イベントのページの地図には、2 つの出し方があります。

| 設定 | 表示 | 閲覧者の通信 |
| --- | --- | --- |
| Google Maps のキーが空（既定） | 「Google マップで開く」「OpenStreetMap で開く」のリンクだけ | ページを開いただけでは外部へ接続しない |
| Google Maps のキーを入れる | 会場の地図を埋め込む | 閲覧者のブラウザーが Google から地図を読み込む |

## 地図を埋め込む

1. Google Cloud で、Maps Embed API を有効にした API キーを作ります。
2. キーを、HTTP リファラーの制限でサイトのドメインに絞ります。キーはページの HTML に出るためです。
3. WordPress の「設定 › EventWatch」を開き、「イベントのページ」の「Google Maps の API キー（任意）」に入れて保存します。

このキーは EventWatch には送りません。Google の利用規約と料金は、サイトのオーナーの責任で確かめてください。

「Google Maps の API キーに使えるのは、半角の英数字・ハイフン・アンダースコアだけです。」と出たときは、キーの全体を正しくコピーできているかを見てください。
