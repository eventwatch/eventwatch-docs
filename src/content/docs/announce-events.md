title: イベントを告知する方法
description: EventWatch にイベントを載せて告知する方法です。載せるとどこに出るか、費用、掲載までの流れ（確認と差し戻し）、Web・AI アシスタント・WordPress プラグインの 3 つの載せ方を説明します。
---

EventWatch は、日本国内のイベントを地域・カテゴリー・日程で探せるサービスです。主催者は、自分のイベントを EventWatch に載せて告知できます。

## 載せるとどうなるか

- EventWatch のイベントの一覧と検索に出ます。探す人は、場所・日程・カテゴリー・キーワードで絞り込めます
- イベントのページに、主催者の名前が「主催」として出ます。名前は、最初に載せるときに決める主催者の表示名です
- イベントのページが SNS などで共有されると、タイトル・説明・画像がプレビューとして出ます

## 費用

料金については、[利用規約](https://eventwatch.app/terms) の第6条（料金および支払）を見てください。

## 掲載までの流れ

載せたイベントは、EventWatch の運営が内容を確認（審査）してから公開します。

| 状態 | 意味 |
| --- | --- |
| 掲載の確認中 | 運営が内容を確認しています。確認が済むと公開されます |
| 公開中 | EventWatch の一覧と検索に出ています |
| 修正のお願い | 直してほしい点があります（差し戻し）。理由を読んで「直して出し直す」から直して保存し、「投稿の管理」で「確認に出す」を押します |

確認は人が行うので、公開まで時間がかかることがあります。確認にかかる日数の目安はお伝えしていません。

## 載せられるイベント

開催日時と開催地が決まっていて、どなたでも参加を検討できるイベントが対象です。載せられるもの・載せられないものは [投稿ガイドライン](https://eventwatch.app/post/guidelines) にあります。送る前に読んでください。

## 載せ方を選ぶ

| 載せ方 | 向いている方 | 始め方 |
| --- | --- | --- |
| Web で投稿する | イベントを 1 件ずつ載せる方。はじめての方 | [イベントを載せる](https://eventwatch.app/post) |
| AI アシスタントで下書きを作る | フライヤーや告知の文があり、入力を AI に任せたい方 | [AI アシスタントで下書きを作る](/ai-assistants/connect) |
| WordPress プラグインで送る | 自分のサイトを WordPress で運営している方（プラグインは公開の準備中で、まだ使えません） | [WordPress プラグインをはじめる](/wordpress/setup) |

### Web で投稿する

1. [イベントを載せる](https://eventwatch.app/post) を開きます。
2. イベントの内容を入れます。必須は、イベント名・開始日時・カテゴリー・開催地（オンライン開催なら不要）の 4 つです。そのほかの項目は、あとから足せます。
3. 「この内容で送る」を押します。ログインは、送るときに Google アカウントで行います。
4. はじめての方は、主催者の名前を入れます。イベントと一緒に表示される名前で、あとから変えられます。

送ったイベントは「掲載の確認中」になります。

自分で入力せずに、イベントのページの URL を知らせて掲載を依頼することもできます（[URL を知らせて掲載を依頼する](https://eventwatch.app/post/request)）。

### AI アシスタントで下書きを作る

Claude や ChatGPT などの AI アシスタントを EventWatch につなぐと、フライヤーの画像や告知の文から下書きを作ってもらえます。AI アシスタントが作るのは下書きまでで、確認に出すのはご自身です。つなぐ前に、Web で 1 件載せて主催者を作っておきます。

つなぎ方は [AI アシスタントで下書きを作る](/ai-assistants/connect) にあります。つないだ後は、次のように頼めます。

- フライヤーの画像を渡して「このフライヤーを EventWatch に下書きで載せて」
- 作った下書きを直すとき「さっきの下書きの開始時刻を 18 時に直して」

### WordPress プラグインで送る

WordPress のサイトで公開したイベントを、そのまま EventWatch に送れます。送る専用のボタンはなく、サイトで公開すると送られます。サイトには、EventWatch の確認を待たずに出ます。

**プラグインは WordPress の公式ディレクトリへの公開を準備していて、まだ使えません。** 公開の後は、先に Web で 1 件載せて主催者を作り、[WordPress プラグインをはじめる](/wordpress/setup) の手順で始めます。

## 載せた後

EventWatch の「投稿の管理」で、載せたイベントを編集・取り下げ・削除できます。

- 公開中のイベントを編集できます。掲載をやめたいときは「取り下げる」を押します
- 掲載の確認中に編集すると下書きに戻り、もう一度確認に出すまで確認は始まりません
- 公開中のイベントは削除できません。取り下げてから削除します。削除すると元に戻せません

WordPress プラグインで送ったイベントは、サイトの側で編集します。
